**SIMDIK** (Sistem Informasi Manajemen Pendidikan) adalah aplikasi berbasis web yang dirancang untuk mengelola dan mengintegrasikan data administratif serta operasional pendidikan secara terpusat, efisien, dan terstruktur. 

Proyek ini dikembangkan sebagai bagian dari **Tugas Akhir / Skripsi** menggunakan metodologi pengembangan perangkat lunak berbasis **Agile Scrum**.

---

## 📌 Fitur Utama

- 🔐 **Autentikasi & Manajemen Peran (RBAC)**: Akses multi-user (Admin, Pengelola/Staf, Tenaga Pendidik/Siswa) sesuai hak akses masing-masing.
- 📊 **Dashboard Edukasi**: Visualisasi ringkasan data statistik instansi secara *real-time*.
- 📂 **Manajemen Data Terpusat**: Pengelolaan master data (data pendidik, kependidikan, serta arsip administratif).
- 📑 **Pelaporan & Ekspor Data**: Rekapitulasi laporan operasional yang dapat dicetak/diekspor secara fleksibel.
- ⚙️ **Pengaturan Sistem**: Konfigurasi profil instansi dan preferensi sistem secara dinamis.

---

## 🛠️ Teknologi yang Digunakan

- **Back-End**: PHP (Laravel Framework)
- **Front-End**: HTML5, CSS3, JavaScript, Bootstrap / Blade Templating
- **Database**: MySQL
- **Web Server**: Apache / Nginx
- **Tools & Environment**: Composer, Git, VS Code
